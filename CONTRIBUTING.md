# Contributing to VECANOVA AI Interview Prep

Thank you for your interest in contributing to the VECANOVA AI Interview Prep platform! We welcome contributions from engineers worldwide to help others master senior AI/ML roles.

## How to Contribute

1. **Fork the repository** and clone your fork locally.
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/new-interview-module
   ```
3. **Install dependencies and test environment**:
   ```bash
   make install
   make test
   ```
4. **Ensure high standards**:
   - Write unit/integration tests for any new code (TDD).
   - Keep documentation updated in `docs/theory/` or `docs/tutorials/`.
   - Run `ruff check` and `pytest` to make sure all quality gates pass.
5. **Open a Pull Request** against the `main` branch with a clear description of your changes.
