# Semantic: Interview Mastery Framework

## Core Principles
1. **Bridge Traditional ML & GenAI**: Never position yourself as purely a prompt engineer or purely a classical data scientist. Enterprise AI requires tabular predictions (XGBoost, anomaly detection, recommendation systems) fed as structured context into LLM agents.
2. **Observability & Evaluation First**: In production healthcare/biotech systems, knowing *why* a model failed (Faithfulness, Context Recall, Latency SLAs) is more important than raw generation capability.
3. **Security & Privacy by Design**: PII/PHI anonymization (Presidio) and guardrails (NeMo) are non-negotiable for enterprise healthcare compliance.
4. **STAR Methodology in English**: Structure every architectural or behavioral answer with Situation, Task, Action, and Result using precise technical vocabulary.
